2. Diseño del paquete: Control Flow y Data Flow

El Control Flow orquesta la corrida (registra el inicio del batch, trunca las tablas temporales, ejecuta el Data Flow, corre el MERGE idempotente y marca el batch OK o ERROR). El staging guarda el dato tal como llega, sin tipar, para trazabilidad y repetibilidad; el Data Flow lo transforma y separa en válidos y casos a revisión. Capturas reales del paquete construido en Visual Studio / SSIS:
