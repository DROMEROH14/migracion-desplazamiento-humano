Ficha técnica del sitio

¿Cómo está construido este proyecto?

Lenguajes

Python Backend, procesamiento y análisis de datos (pandas, scripts de perfilamiento y calidad)
HTML5 + Jinja2 Estructura de las páginas y renderizado dinámico de datos del servidor
CSS3 Diseño visual: tema oscuro, layout, animaciones y efecto de cursor tipo linterna
JavaScript Interactividad: gráficas, contadores animados, filtros y esta misma ficha técnica

Framework y librerías

Flask Framework web en Python: define las rutas, controla las plantillas y sirve la aplicación
pandas Limpieza, integración y perfilamiento del dataset consolidado (28.467 registros)
openpyxl Lectura del archivo Excel original del IDMC durante la construcción del dataset
Chart.js Gráficas interactivas del dashboard y de la sección de Calidad de Datos (empaquetado localmente, sin depender de un CDN externo)
Gunicorn Servidor WSGI de producción usado en el despliegue

Datos y control de versiones

CSV / XLSX / JSON Formatos de almacenamiento del dataset consolidado, diccionario de datos y reporte de calidad
Git + GitHub Control de versiones por rama (feature/etapa-1, feature/etapa-2) e historial de commits

Despliegue

Aplicación publicada en PythonAnywhere, sirviendo el mismo código fuente disponible en el repositorio de GitHub.
